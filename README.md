# StyleSphere Nexus source

This folder contains the editable React source for the StyleSphere vendor onboarding and procurement prototype.

## Development

```powershell
pnpm install
pnpm dev
```

## Build the shareable file

```powershell
pnpm build:share
```

The build creates one self-contained file at `../StyleSphere-Nexus.html`. It can be opened directly in a modern browser without a local server.
